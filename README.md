## Details

This revision of SMPTE RDD 61, the mapping of ARRICORE image essence into the MXF Constrained Generic Container, updates the 2025 edition for ARRI cameras and software released since. It adds essence coding labels for the ARRICORE CBE and VBE Compact Profiles, SubDescriptor items that describe per-camera calibration data, black level and maximum sample value, and six items giving the dimensions and offsets of the base image. A redline against RDD 61:2025 accompanies the draft. Implementers of ARRICORE readers and writers are encouraged to review it and comment through the issue tracker of this repository.
